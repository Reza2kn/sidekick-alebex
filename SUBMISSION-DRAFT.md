## Updated portal description

Sidekick turns voice into a practical interface for blind and low-vision people in Vancouver. Alebex handles the live conversation, fresh location, and local amenity tools; a Gemini vision model reads shared images. Speak a café order, confirm delivery details aloud, and watch the website work in the existing Chrome profile.

Browser decisions now use OpenAI Responses and Decisions. Website actions are supervised by an active Codex operator. The demonstrated cart contained one 50 Assorted Timbits pack, prepared for delivery to the college lab and reviewed at CAD $15.98 with zero tip. The user chose not to purchase.

Verified: live spoken nearby discovery, the fifty-pack request, delivery-contact collection and confirmation, and visible cart preparation. A full voice-triggered purchase and receipt remain unverified. This hackathon prototype needs an active Codex operator for browser tasks; unattended operation and validation with blind users are not claimed.

## Demo setup

Run the local server with your own configuration, keep the signed-in Chrome profile connected, and keep the Codex operator actively running. Complete microphone and location permission prompts once, then press **Start Sidekick**. Supply items and delivery details by voice; no phone number is printed in public materials. Private sign-in and payment setup stay in the website. The OpenAI provider is wired, but a new complete live voice run through it remains unverified. The latest local suite passed 37 tests.
